# Examples

Complete projects checked into the repository under `cmd/examples/`. Each
example is a runnable program; the pages here walk through what it
demonstrates, how to run it, and where to look in the source.

- [kitchen-sink]({{< relref "kitchen-sink" >}}) — every core feature in one
  app: collections, templates, forms, auth, WebSocket chat, static files.
- [gRPC]({{< relref "grpc" >}}) — HTTP + TCP + gRPC transports sharing a
  single kernel.
- [OIDC]({{< relref "oidc" >}}) — OpenID Connect login via the
  contributed `nullspace-oidc` module and Keycloak.

The examples are also covered in the [Tutorials]({{< relref "/tutorials" >}})
when they fit a learning sequence; this section is reference-style and
assumes you want to grab and run.
