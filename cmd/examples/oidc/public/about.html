Architecture Overview

The platform is built on a hexagonal kernel with a hook-driven aspect-oriented middleware pipeline. Inbound requests traverse a configurable chain of transport adapters, format resolvers, and route-level middleware before reaching the application handler.

Authentication is delegated to an external OpenID Connect provider via the Authorization Code + PKCE flow. Token introspection is performed at the edge using encrypted session cookies with AES-GCM, eliminating the need for a centralized session store and reducing per-request latency to sub-millisecond overhead.

Module System

Every component — from logging to CSRF protection to WebSocket broadcast — is a discrete module that implements a four-phase lifecycle: Init, Start, Stop, and declarative configuration via TOML. Modules communicate through a service locator and an asynchronous hook bus, enabling loose coupling without sacrificing observability.

Contributed Modules

Optional capabilities like gRPC transport and OIDC authentication are published as separate Go modules. This keeps heavy dependencies (protobuf, OAuth2 libraries) out of the core framework while allowing applications to compose exactly the feature set they need.
