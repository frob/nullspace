Nullspace Example

This is a sample application built with the Nullspace framework.

Features Demonstrated

  • HTML posts — file-based content with templates
  • JSON API — same data, different format
  • Pretty JSON — with ?pretty=true
  • Contact form — webform module with validation and storage
  • Chat room — real-time WebSocket chat
  • Admin API — protected by Basic Auth (admin / secret)
  • Static files — served from /public
  • Health check — kernel status

Example Modules

  • Auth — Basic auth middleware protecting /api/admin/* routes
  • Forms — Declarative webforms defined in TOML config with validation, file storage, and custom hooks
  • Chat — Real-time chat room using the WebSocket module with room-based broadcast
